Deer Shooter

3D Game · Unreal Engine

Deer Shooter was my first game made in Unreal Engine. The goal is to find and shoot four deer hidden throughout the environment.
Shooting all four completes the game.

I developed this project over five weeks. During this time, I learned the basics of Unreal Engine and how to create a simple playable 3D game.

What did I learn?

  • Working with Unreal Engine
  • Creating and designing levels
  • Working with Blueprints
  • Creating basic gameplay mechanics
  • Building a playable 3D game

What I Created

  • 3D game environment
  • Four hidden deer
  • Shooting mechanic
  • Win condition
  • Complete playable game

My Development

This project was an important first step in learning Unreal Engine. It taught me how to combine levels, Blueprints, and gameplay mechanics into a complete playable experience.
