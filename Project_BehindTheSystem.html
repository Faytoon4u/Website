Behind the System

Serious Game · Narrative · Choice-Based

Behind the System is a serious game about working in closed youth care. You play as Sam, a group worker who works with young people in a residential care environment.

Throughout the game, you encounter different situations where you have to make choices. Every choice you make affects different game variables, such as trust, stress, and safety. These variables change depending on how you interact with the characters and the decisions you make.

The conversations also allow you to get to know the young people better. By talking to them and making different decisions, you gradually learn more about their personalities and situations. At the end of the game, your choices and the variables you have influenced determine which ending you receive.

I got the inspiration for this game after visiting Fontys Pedagogiek. During the visit, I became interested in the work of youth care workers and the difficult situations they can encounter. This inspired me to create a game that gives players an idea of the challenges and decisions involved in working in closed youth care.

I developed the game in Unity using C#. I was responsible for several important systems and parts of the game, including:

  • Creating the dialogue system
  • Creating the choice system
  • Developing the trust, stress, and safety systems
  • Connecting player choices to game variables
  • Creating different endings based on the player's decisions
  • Designing and implementing the UI
  • Creating and implementing assets and sprites
  • Using Scriptable Objects for dialogue and game data

What did I learn?

  • Building a dialogue system in Unity
  • Creating a choice-based game system
  • Working with variables that change based on player decisions
  • Using Scriptable Objects to organize game data
  • Creating different endings based on player choices
  • Combining narrative design with gameplay systems
  • Working with UI and 2D assets in Unity
  • Developing a serious game around a real-world subject

My Development

One of the most important things I learned from this project was how to combine storytelling and programming. Instead of creating a game where choices only change the dialogue, I created systems where decisions have an effect on different variables and eventually influence the outcome of the game.

This project also helped me become more comfortable with Unity and C#. I learned how different systems, such as dialogue, choices, variables, and endings, can work together to create a more interactive and meaningful player experience.

In the end, Behind the System gave me experience in both game development and narrative design, while also allowing me to explore a real-world subject through an interactive experience.
