Blender – 3D Environment

For this project, I worked with Blender for approximately six months, with the goal of learning how to independently create 3D models and complete environments for games.

I started with simple exercises, such as tables, cups, and low-poly trees. In the beginning, I needed a lot of support from tutorials, as I was still learning how to navigate Blender's interface and use its different tools. Over time, I became more independent and was able to create more and more models without relying on tutorials.

During the project, I learned various aspects of Blender, including 3D modelling, Edit Mode, Extrude, Loop Cuts, Bevel, Sculpting, Lighting, and Rendering. I learned how to use simple shapes such as cubes and cylinders to build more complex models. I also experimented with lighting to create different atmospheres and emotions within a scene.

After completing the initial exercises, I started working on my own project: a small tropical island. For this project, I created several 3D assets myself, including a palm tree, treasure chest, surfboard, wooden platform, rocks, roof, bushes, and a seagull. Throughout the project, I increasingly focused on developing my own ideas instead of following tutorials step by step.

An important part of the project was incorporating feedback. Classmates and my teacher gave me feedback on aspects such as the atmosphere, details, and overall environment. Based on this feedback, I added and improved different elements to make the island feel more lively and complete.

In the end, I exported my Blender scene to Unity. During this process, I encountered several problems, such as unclear object names, incorrectly placed origins, and Blender effects that were not properly transferred to Unity. By solving these problems myself, I learned not only how to create models in Blender, but also how to prepare my 3D assets for use within a game engine.

What did I learn?

  • Creating 3D models independently in Blender
  • Working with Edit Mode, Extrude, Loop Cuts, and Bevel
  • Creating low-poly models and game-ready assets
  • Using Sculpting for organic shapes
  • Using Lighting and Rendering to create atmosphere
  • Processing feedback and improving my models
  • Building a complete 3D scene
  • Preparing and exporting models to Unity
  • Solving problems with origins, object names, and imports

My Development

The biggest difference between the beginning and the end of this project is my independence. At the beginning, I relied heavily on tutorials, but later I was able to figure out how I wanted to build an object myself and which Blender tools were best suited for the task.

As a result, I built a solid foundation in Blender over approximately six months and learned how to create my own 3D assets and use them within Game Development.
