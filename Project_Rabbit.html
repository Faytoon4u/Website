Rabbit Adventure

2D Point & Click · HTML · CSS · JavaScript

Rabbit Adventure is a 2D point-and-click game where you play as a little rabbit exploring the neighborhood. Along the way, you can visit a ramen shop or help a neighbor.

This was a school project that I created together with a friend. I was mainly responsible for the visual side of the game and also helped with the programming.

My Contributions

  • Created all game sprites
  • Designed the visual style
  • Created characters and environments
  • Helped with the coding
  • Implemented sprites into the game

Technical Features

  • Point-and-click gameplay
  • Interactive environments
  • Multiple locations
  • HTML, CSS, and JavaScript
  • Sprites created in Aseprite

My Development

This project gave me experience combining 2D art and programming. Creating all the sprites myself also taught me how to keep a consistent visual style throughout a game.
